# RuView Wi-Fi Sensing v2 🚀

Система бесконтактного мониторинга и анализа пространства на основе изменения матриц CSI (Channel State Information) Wi-Fi сигнала. 

## 🗺️ Архитектура системы

Проект разделен на два ключевых компонента:
1. **Сервер (Rust v2):** Высокопроизводительный бэкенд, отвечающий за сбор UDP-пакетов, обработку данных нейросетевыми модулями (`ruv-neural`) и раздачу данных на UI через WebSocket.
2. **Узел сбора данных (ESP32-S3):** Микроконтроллер, переведенный в режим Wi-Fi Promiscuous, который вычленяет CSI-пакеты и отправляет их на сервер.

---

## 💻 Текущий статус и настройка сервера

* **Сборка:** Полностью собран в режиме `--release`.
* **Веб-интерфейс:** Доступен по адресу `http://localhost:8095/ui/index.html`.
* **Порты:** 
  * `HTTP: 8095` — веб-панель и API.
  * `UDP: 5005` — входящий порт для CSI-пакетов (открыт в Брандмауэре Windows).
* **Сетевое имя (mDNS):** Компьютер определен в локальной сети как `Pavel-888.local`.
* **Режим симуляции:** Успешно протестирован в режиме `SIMULATED` (~183 FPS, 2 WebSocket-клиента).

### Запуск сервера
```bash
cd v2
cargo run --release --bin sensing-server
```

---

## 🔌 Прошивка (ESP32-S3)

Микрокод локально скомпилирован. Внедрена функция автоматического поиска сервера через mDNS (`getaddrinfo`), что позволяет плате самостоятельно находить хост `Pavel-888.local` без жесткого прописывания IP-адреса в коде.

### Спецификация сетевого взаимодействия
* **Протокол:** UDP
* **Порт назначения:** 5005
* **Цель назначения:** `Pavel-888.local`

---

## 🌲 Особенности работы в реальных условиях (Лес / Открытый воздух)
* **Зона Френеля:** В отсутствии стен фиксация перемещений происходит преимущественно на линии прямой видимости между передатчиком и приемником.
* **Фильтрация шума:** Алгоритмы адаптированы к статичным препятствиям (деревьям), однако ветреная погода (качающиеся ветки) создает естественный шум, требующий корректировки порогов чувствительности в UI.
